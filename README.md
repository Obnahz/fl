# 挂机也成仙

以修仙为主题的浏览器放置游戏。

在线体验：<https://obnahz.github.io/fl/>

## 当前版本

**V2.0.1 板块重新分工稳定版**

游戏围绕一个共同阶段目标组织各板块：

```text
阶段目标 → 板块准备 → 路线选择 → 突破结算 → 成功进入下一境界 / 失败复盘后重新准备
```

准备组合会形成三种路线：

- **稳修路线**：成功率小幅提升，失败损失降低。
- **均衡路线**：在成功率和失败保护之间取中间值。
- **历练路线**：成功率提升更多，但失败损失也更高。

突破失败后会自动开启同境界的新准备周期，同时保留上一轮结果。

## 主要玩法

- 角色创建与灵根测定
- 手动、自动修炼与境界突破
- 功法解锁、装备和升级
- 探索地点、机缘、资源与装备获取
- 炼丹与丹药使用
- 装备穿戴、强化、比较和整理
- 宗门、修炼方向与宗门事务
- 洞府值守、离线收益与领取
- 秘境多层探索、战斗与增益选择
- 日常任务、七日目标和成就
- 本地存档导入导出与明暗主题

## 技术栈

Vue 3、Vite、Vue Router、Pinia、Naive UI、Web Workers、Node.js 原生测试。

## 本地运行

需要 Node.js 20 或更高版本，以及 pnpm。

```bash
pnpm install
pnpm run dev
```

开发服务器默认地址：<http://localhost:2025/>

## 构建与测试

```bash
pnpm run build
pnpm test
```

生产构建产物输出到 `docs/`，GitHub Pages 站点为：<https://obnahz.github.io/fl/>

## 数据说明

游戏进度保存在浏览器本地。清理站点数据可能会删除进度；更换设备前请在“设置”中导出存档。旧存档会在加载时自动补齐新版本字段。
