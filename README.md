# 挂机也成仙

一个以修仙为主题的浏览器放置游戏。

在线体验：<https://obnahz.github.io/fl/>

## 项目简介

你可以创建自己的修士，在持续增长的灵力中安排修炼、功法、装备、探索和秘境挑战。游戏状态保存在浏览器本地，适合短时间查看，也适合隔一段时间回来继续修行。

## 主要内容

- **角色创建**：输入道号并随机测定灵根。
- **修炼**：手动修炼、自动修炼、闭关至圆满和境界突破。
- **功法**：解锁、装备和升级功法，管理出战套路。
- **背包与装备**：查看物品、装备法器、强化和比较装备属性。
- **探索**：前往不同地点历练，获取资源、装备和机缘。
- **炼丹**：选择已掌握的丹方，检查材料并炼制丹药。
- **秘境**：进行探索和战斗，面对妖兽、首领与特殊奖励。
- **抽奖**：使用对应资源抽取奖励。
- **成就**：查看各类成就和当前完成进度。
- **存档**：在设置中导出或导入本地存档。
- **主题切换**：支持明亮和暗色主题。

## 技术栈

- Vue 3
- Vite
- Vue Router
- Pinia
- Naive UI
- Web Workers
- Node.js 原生测试

## 本地运行

需要 Node.js 20 或更高版本，以及 pnpm。

```bash
pnpm install
pnpm run dev
```

开发服务器默认地址：

```text
http://localhost:2025/
```

## 构建与预览

构建生产版本：

```bash
pnpm run build
```

构建产物会输出到 `docs/`，可使用以下命令本地预览：

```bash
pnpm run preview
```

预览服务器默认地址：

```text
http://localhost:2026/
```

## 测试

运行游戏规则和存档校验测试：

```bash
pnpm test
```

测试覆盖战斗、探索、装备、功法、奖励、突破、存档校验和内容扩展等核心逻辑。

## 部署

项目已经包含 GitHub Pages 工作流：

```text
.github/workflows/deploy-pages.yml
```

推送到 `main` 分支后，GitHub Actions 会自动执行构建并发布 `docs/` 产物。

当前站点地址：

```text
https://obnahz.github.io/fl/
```

如果修改了部署路径，请同步检查 `vite.config.js` 中的 `base` 配置，以及 GitHub Pages 的发布来源。

## 数据说明

- 游戏数据默认保存在当前浏览器的本地存储中。
- 清理浏览器站点数据可能会删除本地进度。
- 更换设备或浏览器前，请先在“设置”中导出存档。
- 导入存档前建议保留一份当前存档备份。

## 目录结构

```text
src/
├─ components/   可复用界面组件
├─ plugins/      游戏规则、内容与数据定义
├─ router/       路由配置
├─ stores/       Pinia 状态与本地存档
├─ views/        游戏页面
└─ workers/      灵力、修炼、探索与日志 Worker

public/           静态资源
docs/             GitHub Pages 构建产物
tests/            核心规则测试
```
