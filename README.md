# 挂机也成仙

一款以修仙为主题的浏览器放置游戏。玩家可以在离线状态下积累资源，并通过修炼、历练、炼丹、功法、装备、洞府、宗门、秘境和坊市逐步成长，最终突破至大罗境。

在线体验：<https://obnahz.github.io/fl/>

## 当前版本

**V2.8：平衡与表现**

本版本重点统一品质体系、调整历练与灵兽掉落节奏、修复装备成就判定，并持续优化背包、炼丹和全局操作体验。

## 主要内容

- 角色创建、灵根选择、修炼和境界突破
- 从凡品到仙品的统一品质体系
- 低境界也有机会获得高品质物品，高境界提高获得概率并增强同品质强度
- 历练地点、随机事件、战斗、装备掉落和完整灵兽获取
- 灵草采集、丹药配方、品质炼丹和丹药效果
- 功法解锁、升级、传承和战斗选择
- 装备穿戴、品质比较、战力评分、套装、强化和整理
- 宗门事务、洞府值守、离线收益和秘境探索
- 日常任务、七日目标、阶段目标与成就
- 坊市交易与资源循环
- 本地存档导入、导出、压缩与兼容旧存档

游戏不使用抽奖系统。灵兽可以在历练过程中直接获得，历练难度越高，获得高品质、高强度灵兽的概率越大。

## 本地运行

需要 Node.js 20 或更高版本，以及 pnpm。

```bash
pnpm install
pnpm run dev
```

开发服务器默认地址：<http://localhost:2025/>

## 构建与测试

```bash
pnpm run build
pnpm test
```

生产构建输出到 `docs/`，GitHub Pages 地址为：<https://obnahz.github.io/fl/>

## 存档说明

游戏进度保存在浏览器本地。更换设备或清理站点数据前，请先在“设置”中导出存档。导出的文件名使用“挂机也成仙”，旧版存档仍会在导入时自动兼容和迁移。

## 技术栈

Vue 3、Vite、Vue Router、Pinia、Naive UI、Web Workers、Node.js 原生测试。
